# TechBox — контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Учебный интернет-магазин техники на основе собственной работы №1 `kr1-html-css-shop`. Сохранены товары, фотографии, оформление и многостраничная структура. Bootstrap и другие CSS-фреймворки не используются.

## Запуск

Откройте `index.html` в браузере либо запустите из папки проекта:

```sh
python3 -m http.server 8123 --bind 127.0.0.1
```

Адрес: [локальный сайт](http://127.0.0.1:8123/). Серверная обработка заявок отсутствует: формы проверяют данные и показывают учебное подтверждение.

## Адаптивные решения

На всех десяти страницах есть `viewport`; `responsive.css` подключён после `style.css`. Базовые правила рассчитаны на телефон, дополнительные возможности включаются через `min-width`.

| Ширина | Поведение |
| --- | --- |
| До 640 px | Одна колонка карточек и полей, кнопки hero друг под другом, характеристики карточками строк |
| От 640 px | Две колонки товаров и преимуществ, двухколоночная форма заявки |
| От 768 px | Фото и описание товара рядом, характеристики обычной таблицей, увеличенные отступы |
| От 1024 px | Горизонтальная навигация, три колонки популярных товаров, четыре преимущества, боковые sticky-фильтры и две колонки каталога |
| От 1200 px | Три колонки каталога при ограниченной ширине общего контейнера |

- Меню использует Flexbox, сетки товаров, преимуществ и формы — Grid.
- `minmax(0, 1fr)`, `min-width: 0` и перенос длинных слов предотвращают переполнение.
- На телефоне статический блок фильтров расположен над товарами; на большом экране — сбоку с `position: sticky`. Фильтрация остаётся статической, как в КР №1.
- Сетка формы расширяется до двух колонок, комментарий и согласие занимают всю ширину. Диалог сохраняет одну колонку и прокручивается внутри при небольшой высоте экрана.
- Таблицы всех шести товаров на телефоне показывают строки как карточки: название характеристики над значением. `caption`, заголовки столбцов, `scope` и роли сохраняют связи для вспомогательных технологий. Дополнительно есть контейнер с локальной прокруткой.
- Карта, подвал, цены, хлебные крошки и кнопка «Наверх» подстраиваются под экран.

## Responsive images

Для всех шести товаров подготовлены настоящие файлы 400×300 и 800×600 в JPEG и WebP. `picture` предлагает WebP, `img` оставляет JPEG как запасной формат; `srcset` и `sizes` позволяют выбрать размер по ширине контейнера и плотности экрана. Указаны `width`/`height`, соотношение сторон 4:3 и осмысленные `alt`. Изображения карточек загружаются отложенно, основное фото товара — сразу. Базовое правило `max-width: 100%; height: auto` действует для изображений и видео.

## Доступность

- На каждой странице один `h1`, русский язык документа, уникальное название страницы, смысловые области `header`, `nav`, `main`, `footer`.
- Первой по Tab доступна ссылка «Перейти к основному содержимому»; она переводит фокус на `main`.
- Все интерактивные элементы имеют видимый фокус; кнопки и основные поля не ниже 44 px, шрифт полей — 16 px.
- Навигация постоянно видна: на телефоне ссылки располагаются вертикально, на большом экране — горизонтально с переносом. Управление доступно с клавиатуры без дополнительных сценариев JavaScript.
- Вёрстка, навигация и статические фильтры работают без JavaScript. Файл `js/main.js` полностью совпадает с исходной КР №1; новых обработчиков событий не добавлено.
- Сохранён исходный нативный `dialog` с заголовком, открытием и закрытием из КР №1. Ограничение высоты и внутренняя прокрутка добавлены через CSS.
- Поля связаны с `label`, сохранены `required` и HTML-ограничения. Добавлены `autocomplete`, `inputmode` и связанная через `aria-describedby` подсказка формата телефона. Исходный скрипт отмечает неверные поля через `aria-invalid` и вызывает стандартные сообщения браузера.
- У сообщения об успешной проверке заявки указан `role="status"`.
- Рамки полей усилены до `#767676`, текст и кнопки используют контрастную палитру исходного проекта. Ошибочные поля выделяются рамкой; пояснения выводит встроенная проверка браузера.
- Декоративный логотип имеет пустой `alt`, фотографии — названия товаров, карта — `title`. Телефон и почта оформлены ссылками.
- Учитываются `prefers-reduced-motion` и системный режим высокой контрастности; добавлены стили печати.

## Проверка

Основные ширины по заданию: **360, 430, 768, 1024, 1440 px**; дополнительная — **320 px**. Проверяются все десять страниц, отсутствие горизонтального переполнения, изображения, заголовки, постоянная навигация, исходный диалог, исходная проверка формы и предвыбор товара.

Повторный запуск:

```sh
npm install
npx playwright install chromium
# В отдельном терминале: npm start
npm test
npm run audit
```

`npm run audit` запускает Lighthouse в мобильном режиме с категорией Accessibility для главной, каталога и заявки и сохраняет HTML/JSON в `lighthouse/`. Автоматический аудит дополняется проверкой клавиатуры и интерфейса; высокий балл сам по себе не доказывает полную доступность.

## Самостоятельные доработки

Карточное представление характеристик; два размера изображений в двух форматах; skip-link; адаптивные формы и диалог; улучшенный контраст полей; режим уменьшенного движения; повторяемые проверки всех страниц. Все изменения сайта выполнены в HTML/CSS, файл JavaScript сохранён из КР №1 без изменений.
