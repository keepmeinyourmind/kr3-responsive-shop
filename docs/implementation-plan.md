# План КР №3

Основа — TechBox из КР №1. Изменения выполняются в HTML/CSS; js/main.js сохранён без изменений.

1. Отдельный проект kr3-responsive-shop, без Bootstrap.
2. Mobile First: responsive.css после style.css на всех десяти страницах.
3. Постоянно доступная адаптивная навигация; статические фильтры над каталогом на телефоне и сбоку на desktop.
4. Адаптивные hero, сетки, формы, контакты, таблицы и исходный диалог.
5. Реальные JPEG/WebP 400 и 800 px, picture, srcset, sizes.
6. Skip-link, фокус, контраст, label, alt и связанные подсказки.
7. Проверка страниц на 320, 360, 430, 768, 1024, 1440 px, исходной формы и диалога.
8. Актуальные Lighthouse-отчёты, README и протокол проверки.
