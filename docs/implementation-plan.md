# План выполнения КР №3

Цель: адаптировать существующий TechBox из КР №1 и проверить доступность.
Основа: собственные HTML/CSS, без Bootstrap; существующие товары и оформление сохраняются.

1. Перенести основу в отдельный проект kr3-responsive-shop.
2. Добавить css/responsive.css после style.css на всех десяти страницах: мобильная база, расширения от 640, 768, 1024 и 1200 px.
3. Адаптировать шапку, меню, hero, сетки, каталог, формы и контакты. Меню доступно без JavaScript; с JavaScript поддерживает раскрытие, Escape и возврат фокуса.
4. Подготовить реальные JPEG/WebP в размерах 400 и 800 px, подключить picture, srcset, sizes.
5. Превратить таблицы характеристик на телефоне в карточки строк с сохранением семантики таблицы.
6. Добавить skip-link, видимый фокус, связанные подсказки и ошибки форм, доступное модальное окно и форму обратной связи.
7. Проверить все страницы на 360, 430, 768, 1024, 1440 px, дополнительно 320 px и масштабирование. Проверить клавиатуру, формы, меню, диалог, изображения и локальные ссылки.
8. Сохранить реальные Lighthouse Accessibility отчёты для index, catalog, order; описать результаты и самостоятельные доработки в README.
9. Подготовить самостоятельный Git-репозиторий с обычными сообщениями коммитов и автором из исходного проекта.

Особые проверки: закрытое меню не получает фокус; переход с desktop на mobile не скрывает текущий фокус; диалог помещается на низком экране; длинные значения и ошибки не расширяют страницу; сайт читается без JavaScript.
