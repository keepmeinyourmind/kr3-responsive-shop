# Протокол проверки КР №3

Дата: 2 ноября 2026 года. Среда: локальный HTTP-сервер, Chromium, Lighthouse 13.6.0, axe-core.

## Разметка и ресурсы

Все десять страниц содержат один h1, уникальные идентификаторы, существующие локальные ссылки, связанные подписи полей и alt изображений. Проверен синтаксис JavaScript. Адаптивные стили подключены после основных.

## Размеры экрана

Автоматически проверены index, catalog, order, contacts и шесть страниц товара на ширинах 320, 360, 430, 768, 1024, 1440 px при высоте 900 px: 60 сочетаний, горизонтального переполнения нет. Подробности сохранены в viewport-results.json.

## Сценарии

- Мобильное меню открывается кнопкой, обновляет aria-expanded, закрывается по Escape и возвращает фокус. Закрытые ссылки не получают Tab.
- При расширении экрана фокус с кнопки меню переходит на навигацию.
- Skip-link — первый элемент Tab-порядка; Enter переводит фокус на main.
- Диалог открывается с кнопки товара, закрывается по Escape и возвращает фокус на исходную кнопку. Tab циклически обходит поля и кнопки; диалог помещается в экран 360×480.
- Пустая заявка показывает связанные текстовые ошибки и aria-invalid; корректные данные проходят проверку и показывают учебное подтверждение. Товар подставляется из URL.
- Фильтр смартфонов оставляет один товар, сброс возвращает шесть.
- Без JavaScript навигация и фильтры открыты.
- В дереве доступности мобильной таблицы присутствуют table, row, columnheader, rowheader, cell. Снимок сохранён в table-accessibility.txt.
- Ошибок выполнения скриптов при проверенных сценариях не обнаружено.

## Аудит

Lighthouse Accessibility в мобильном режиме 360×800: index 100/100, catalog 100/100, order 100/100. Оригинальные HTML- и JSON-отчёты находятся в lighthouse/. Проведены повторные запуски после доработок формы.

axe-core с правилами WCAG 2 A/AA и WCAG 2.1 AA проверил все десять страниц на мобильной ширине: 0 нарушений. Полный результат — axe-results.json. Это автоматические проверки; отдельное тестирование экранным диктором не проводилось.

## Визуальный контроль

Просмотрены снимки мобильной главной, каталога на 1440 px и мобильной страницы товара: блоки читаемы, изображения сохраняют пропорции, элементы помещаются по ширине, характеристики представлены карточками строк. Сохранены также снимки заявки и контактов.
