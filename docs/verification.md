# Проверка КР №3 после возврата исходного JavaScript

Файл js/main.js побайтово совпадает с КР №1. Добавленные обработчики меню, фильтров, текстовых ошибок и циклического Tab удалены. Навигация постоянно видна и адаптируется через CSS. Фильтры сохранены статическими.

## Проверяемые сценарии

Все десять страниц на ширинах 320, 360, 430, 768, 1024, 1440 px: отсутствие горизонтального переполнения, один h1, загрузка изображений. Проверяются исходные открытие диалога, Escape и возврат фокуса, предвыбор товара из URL, исходная проверка пустой и заполненной заявки. Также проверяются постоянная навигация, статические фильтры, skip-link и высота диалога на 360×480.

Результаты размеров сохраняются в viewport-results.json. Результат axe по WCAG 2 A/AA и WCAG 2.1 AA на десяти страницах — в axe-results.json. Дерево доступности мобильной таблицы — в table-accessibility.txt. Снимки страниц обновляются после изменений. Отдельное тестирование экранным диктором не проводилось.

Lighthouse повторно проверяет index.html, catalog.html, order.html в мобильном режиме. Актуальные HTML- и JSON-отчёты находятся в lighthouse/.

На contacts.html добавлена адаптивная форма обратной связи с именем, e-mail и сообщением. Для проверки используется исходный js/main.js без изменений. Проверяются ошибки пустой формы и учебное подтверждение заполненной формы.
